# Task 11 report — shared Music widget renderer

Task 11 is implemented on `codex/add-music-widget-module`. The renderer consumes the validated `MusicWidgetProjection`, uses its server-owned appearance epoch and observation time, and draws one production component in browser overlays, Storybook and the private desktop overlay. Null, invalid, empty-track and stale projections leave no host, branding or content. No provider, user Pear data or live output configuration was changed.

## Interfaces for Tasks 12, 13 and 15

- `MusicWidget({ projection: MusicWidgetProjection | null, resolveAsset: MusicAssetResolver, nowEpochMs?: number, reducedMotion?: boolean })` lives in `apps/web/src/overlay/components/MusicWidget.tsx`. `nowEpochMs` is an optional deterministic preview/test clock; production uses `Date.now()` with a bounded interval. The existing `getMusicPositionMs` owns nullable timing and pauses/seeks; the renderer never invents unknown duration or position. Image selection does not change width or height. The explicit aspect-ratio editor action remains Task 13.
- `OverlaySurface` accepts optional `resolveMusicAsset: MusicAssetResolver` beside its existing `resolveAssetUrl(assetId, version)` callback. It dispatches `music-widget` only on a visible module layer. Browser `OverlayApp` resolves versioned uploaded media with `createOverlayAssetUrl` and opaque artwork with `createOverlayMusicArtworkUrl`; purpose/profile checks remain in that helper and server routes.
- `DesktopOverlayController.getSnapshot().modules[]` now carries `artwork: PrivateDesktopMusicArtwork | null` with its revision, presentation and asset URL map. `DesktopOverlayApp` resolves exact uploaded asset versions from that map and only creates `privateDesktopMusicArtworkUrl` when ref/provider/generation match the current Music presentation. A clear/replacement removes the old renderer resource view. The renderer never sees `mart_` grants.
- Advanced CSS code imports `validateMusicCss` or `compileMusicCss` from `@stream-jams/core/music-style-policy`. The root core export was removed because it pulled `css-tree` into every route. The renderer dynamically imports the same shared compiler only for enabled, nonempty CSS and drops obsolete or unmounted compile results. Invalid persisted CSS falls back to native styles.
- Missing brand or font media falls back to the native fill/font; failed artwork removes the image and uses the placeholder. Task 13 can surface saved asset availability through its typed management API. There is no new renderer-to-management diagnostic callback in this checkpoint; Task 15 should verify live diagnostics and transparent clearing end to end.

## Rendering and UX boundary

The Shadow DOM exposes the documented `.sj-content`, artwork, title, artists, album, progress, time and brand image parts. Exactly six color-valued native variables are set on `.sj-content`. Native controls set geometry, typography, colors, independent fill and brand opacity, image fit/position and content insets. Validated custom CSS follows native styles in a later cascade layer. The managed host and shadow wrappers own absolute placement, paint containment, clipping, pointer behavior, visibility and fill/image/content stacking outside editable selectors. A first cascade layer enforces reduced motion on all inner elements and pseudo-elements, even against stronger custom `!important` animations. Metadata is React text, and only schema-validated attribution links are emitted.

Applicable historical MVP UX sections reviewed: §2 Product Surfaces (management setup versus transparent output), §3 Information Architecture (module/profile output ownership), §4 Visual Foundation and Accessibility (legibility and reduced motion), §7 Assets (saved asset IDs and replacement), §10 Target Profiles, plus the overlay error presentation rule. Music is the approved OpenSpec extension beyond the historical MVP; player commands, audio, request history and other providers remain out of scope. Loaded, compact, branded, custom CSS, long text, missing media, invalid saved CSS and cleared output states have production-component Storybook stories. Overlay has no keyboard controls; attribution links are schema-safe, while the broadcast host intentionally suppresses pointer input.
